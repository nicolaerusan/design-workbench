# DesignBench logo studies

Four original editable SVG options. Open logo-options.svg for the comparison sheet. Each mark uses currentColor, a 48×48 viewBox, and no fonts or external dependencies.

1. Joinery — solid workbench silhouette; recommended for small sizes.
2. Trestle — lighter, open workshop mark.
3. Modules — independent components forming a bench.
4. Fold — continuous outlined bench with depth.

Selected mark: **02 Trestle**, copied to designbench.svg and used in the app sidebar and favicon.
